# EAC dsh-dpx 隔离安装 — 文件索引（交付清单）

配套文档：
- 决策依据：`docs/adr/0004-eac-install-environment-isolation.md`
- 运维与人工测试：`docs/HANDOVER-EAC-ISOLATION.md`

本文档回答一个问题：**这次 dsh-dpx 隔离工作一共动了哪些文件、各自为什么在那个位置。**
它是 review / 交接用的清单，不是操作手册。

---

## 0. 为什么文件"看起来散落"

它们分布在 7 个目录，但**不是乱放**——每个位置都由硬依赖锁定。下表是"位置 → 谁在依赖它"，
理解这张表之后再看待办事项里的"能不能集中迁移"就有答案了。

| 目录 | 定位 | 硬依赖（动了会断什么） |
| --- | --- | --- |
| `dsh-desktop/lib/desktop/` | L2 sidecar 业务模块 | sidecar `mount()` 按名加载；`tsconfig.json` 编译面；`stage-resources.mjs` 的 `LIB_DESKTOP` 清单 |
| `dsh-desktop/scripts/` | 随包运行期脚本 | `stage-resources.mjs` 的 `SCRIPTS` 清单从该目录取；Rust 按 `<resources>/dsh-desktop/scripts/…` 定位 |
| `dsh-desktop/test/` | Node 测试 | `npm test` 的 glob 是 `test/*.test.ts` —— **不在该目录就静默不运行** |
| `tauri-shell/` | L1 Rust 壳 + 构建期脚本 | CI 有 `run: node tauri-shell/<script>.mjs`；`stage-resources.mjs` 用 `./` 相对 import |
| `tauri-shell/src/` | L1 Rust 源码 | Cargo 构建面 |
| `docs/adr/`、`docs/` | 决策与交接文档 | CI `paths:` 过滤器盯 `docs/adr/` |
| `reports/` | 验收证据 | 无硬依赖（唯一可自由挪动的一类） |
| `third_party/dsh-dpx/` | submodule（固定提交） | `.gitmodules`；`check-dpx-pin.mjs` 校验 |

## 1. 新增文件（15 项）

### 1.1 运行期源码

| # | 路径 | 行数 | 作用 |

| 1 | `dsh-desktop/lib/desktop/environment.ts` | 636 | **L2 隔离适配器**：唯一的环境隔离实现入口。调 dsh-dpx 的 JS API（`createEnvironment` / `pathsFor` / `runtimeEnvironment` / `readRegistryReport` / `environmentManifestReport` / `environmentRemovalPlan` / `removeEnvironment`），产出隔离根路径与子进程 runtime。含 P1 运维面 `diagnoseEacEnvironment` / `removeEacEnvironment`。**不复制** dpx 的注册表、锁、清单、变量治理逻辑（ADR 0002 分层）。 |

## 3. 路径依赖速查（改文件前必看）

```text
environment.ts
  ├─ 被 dsh-desktop/tsconfig.json 编译 → lib/desktop/environment.js
  ├─ 被 tauri-shell/sidecar/server.ts 经 mount('environment') 加载
  └─ 被 stage-resources.mjs 的 LIB_DESKTOP 清单按名拷贝

environment-diagnose.mjs
  ├─ 由 stage-resources.mjs 的 SCRIPTS 清单从 dsh-desktop/scripts/ 取
  ├─ 被 main.rs 按 <resources>/dsh-desktop/scripts/environment-diagnose.mjs 定位
  └─ 内部用 ../lib/desktop/environment.js 相对定位适配层

stage-node-modules.mjs / check-dpx-pin.mjs
  ├─ 被 stage-resources.mjs 用 ./stage-node-modules.mjs 相对 import
  ├─ 被 CI 用 node tauri-shell/<name>.mjs 调用（3 处）
  └─ 内部用 import.meta.url 上溯仓库根

eac-*.test.ts
  └─ 必须留在 dsh-desktop/test/：npm test = node scripts/test-runner.js test/*.test.ts
```

**结论：源码（1.1）与测试（1.2）不可移动**；仅文档（1.3）与证据（1.4 两类）在无硬依赖意义上可自由归置。
如需归置，`reports/` 是唯一零联动成本的目标。
